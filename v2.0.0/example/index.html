Worked example

Vertices need a String property :name.

using SamplingPerceivedNetworks, Graphs, MetaGraphs, Random

g = MetaGraph(watts_strogatz(100, 6, 0.2; rng = MersenneTwister(1)))
for i in vertices(g)
    set_prop!(g, i, :name, "p$i")
end

One perceiver

orbit = vertexorbit(g, 1, 3)
bins  = samplingbins(orbit, 3)

With moreinfo = true, samplebins also returns the degree bin and reality of each sampled pair:

lst, degrees, real = samplebins(
    MersenneTwister(2), bins;
    desired = ((3, 3), (3, 3), (3, 3)), dvals = (1, 2, 3), moreinfo = true,
)

The whole network

lists = samplenetwork(
    MersenneTwister(3), g;
    desired = ((5, 5), (5, 5), (5, 5)), dvals = (1, 2, 3), moreinfo = true,
)
length(lists)
100

psn_edgelists flattens the lists into a table for export (for example, with CSV.jl):

el = psn_edgelists(lists)

Note

Looking up a vertex by name, as in vertexorbit(g, "p1", 3; index = false), requires set_indexing_prop!(g, :name). Integer vertex indices do not. The output converts node names to String.
