API reference

Orbits and bins

SamplingPerceivedNetworks.vertexorbit — Function
    vertexorbit(graph::T, vertex, dₘₐₓ; index = true) where T <: MetaGraph

Generate the social orbit of a perceiver on an undirected, unweighted network (a MetaGraph whose vertices have a :name property). The orbit contains everyone within dₘₐₓ steps of the perceiver, who is removed from the returned graph. Edges carry the properties :d (distance) and :real (whether the tie exists in graph).

If index is true, vertex is the vertex index; otherwise it is the node name, which requires set_indexing_prop!(graph, :name). name is the property that holds node names.

source
SamplingPerceivedNetworks.vertexorbit_d — Function
    vertexorbit_d(rad, d) where T <: MetaGraph

Restrict a social orbit to the ties that first appear at distance d, removing those at all other distances. rad is the output of vertexorbit.

source
SamplingPerceivedNetworks.samplingbins — Function
    samplingbins(orbit, dₘₐₓ)

Group every candidate pair in orbit (the output of vertexorbit) into sampling bins, keyed by (distance, is_real). Each bin is a vector of name pairs, and the bins are the sets from which samplebins draws.

source
    samplingbins(orbit, dₘₐₓ, consents)

As samplingbins(orbit, dₘₐₓ), omitting pairs in which either node has not consented to photos (consent code below 2).

Arguments ≡≡≡≡≡≡≡≡≡≡≡

  • orbit: the output of vertexorbit
  • dₘₐₓ: the maximum distance the orbit was built with
  • consents: a map from each node name to its consent code

Sampling

SamplingPerceivedNetworks.samplebins — Function
    samplebins(
        [rng],
        bins;
        desired = deployed_design.desired, dvals = deployed_design.dvals,
        moreinfo = false, carryover = true
    )

Sample from bins to generate the CSS list for one perceiver, as a vector of pairs. With moreinfo = true, also return the degree bin and the reality of each pair. dvals must be in increasing order.

If rng is given, every draw uses it. samplenetwork passes each perceiver's own seeded generator.

When a bin, given as (degree, reality), is smaller than the desired number, other bins are oversampled so that the total desired number (or the maximum possible number) is reached for that survey.

With carryover = true (the default), shortfalls are carried forward. A real bin that cannot supply the desired number is topped up from the real bin at the next degree. A real shortfall remaining after the last degree is made up from the counterfactual bins.

Arguments ≡≡≡≡≡≡≡≡≡≡≡

  • [rng] : random number generator, e.g., MersenneTwister(2)
  • bins: full sampling bins from which to sample
  • desired: tuple of (# real, # counterfactual) for each degree bin in dvals
  • dvals: degree bins, in increasing order; each is an integer or a range of integers (combining degrees into one bin). Must be the same length as desired
  • moreinfo: if true, also return the degree bin and the reality of each pair
  • carryover: if false, a bin smaller than desired is not made up from other bins, so the list is shorter; this is the procedure as described in Feltham et al. (2025)
source
SamplingPerceivedNetworks.samplenetwork — Function
    samplenetwork(
        [rng],
        graph;
        desired = ((5, 5), (5, 5), (5, 5), (5, 5)),
        dvals = (1, 2, 3, 4),
        moreinfo = false,
        shuffle = true,
        carryover = true
    )

Generate, for each person in an unweighted, undirected sociocentric network, a list of relationships to show them, using the social orbit procedure. For each degree bin in dvals, sample real and counterfactual pairs in the numbers given by desired.

dvals contains integers or integer ranges (a range combines several degrees into one bin). desired has one tuple (# real, # counterfactual) for each element of dvals, in the same order.

By default a bin smaller than desired is made up from other bins (see samplebins), so lists keep their full length where possible. With carryover = false each bin supplies at most its own desired number, as in the procedure described in Feltham et al. (2025), and a short bin gives a shorter list.

Optionally specify a random number generator (rng).

source
    samplenetwork(
        [rng],
        graph,
        consents;
        desired = ((5, 5), (5, 5), (5, 5), (5, 5)),
        dvals = (1, 2, 3, 4),
        moreinfo = false,
        shuffle = true,
        carryover = true
    )

Generate, for each person in an unweighted, undirected sociocentric network, a list of relationships to show them, using the social orbit procedure. For each degree bin in dvals, sample real and counterfactual pairs in the numbers given by desired.

dvals contains integers or integer ranges (a range combines several degrees into one bin). desired has one tuple (# real, # counterfactual) for each element of dvals, in the same order.

By default a bin smaller than desired is made up from other bins (see samplebins), so lists keep their full length where possible. With carryover = false each bin supplies at most its own desired number, as in the procedure described in Feltham et al. (2025), and a short bin gives a shorter list.

Optionally specify a random number generator (rng).

Consent codes in consents (a Dict from node name to code): 0 = none, 1 = survey only, 2 = survey and photo, 3 = photo only. Only perceivers with code 1 or 2 receive a list (others are absent from the result); a pair is included only if both nodes have code ≥ 2, so a perceiver may get a short or empty list. Every node must have an entry (ArgumentError otherwise).

source
SamplingPerceivedNetworks.deployed_design — Constant
    deployed_design

Preset for the desired and dvals keywords (splat it in, e.g., samplenetwork(graph; deployed_design...)): the design fielded in the Honduras CSS. Four separate degree bins, 5 real and 5 counterfactual in each. This is the default of samplenetwork, samplebins and inclusionprobs.

source
SamplingPerceivedNetworks.merged_design — Constant
    merged_design

Preset for the desired and dvals keywords: an alternative that combines degrees 1 and 2 into one bin with 10 + 10 (and 5 + 5 at degrees 3 and 4). It was never deployed.

SamplingPerceivedNetworks.inclusionprobs — Function
    inclusionprobs(graph, v[, consents]; desired, dvals, carryover)
    inclusionprobs(graph[, consents]; desired, dvals, carryover)

Exact first-order inclusion probabilities of the stratified draw in samplenetwork, computed from the graph without any random sampling.

The first form is for the perceiver at vertex v. The second stacks all perceivers (when consents is given, only those who would receive a list: code 1 or 2) and adds a perceiver column. Both return a DataFrame with one row for every pair that could be shown, with columns from and to (each pair sorted alphanumerically), bin (the degree bin, e.g., "1:2"), real (whether the pair is a real tie) and pi (the probability that the pair is on the perceiver's list). Pairs outside the orbit, or in a bin beyond dvals, are not listed; their probability is zero. For a perceiver who has no list, the second form has no rows.

Within a bin the draw is a simple random sample without replacement, so pi = n / N: N is the size of the bin and n the number drawn, after the gap carry-over (see samplebins; carryover = false turns it off). The weight for estimation is 1 / pi.

pi is the probability that a pair is on the list samplenetwork produces, not that it was answered: respondents who do not recognize someone in a pair are not asked about it, and this is not modeled. consents follows samplenetwork: a pair is eligible only if both nodes have code ≥ 2.

Utilities

SamplingPerceivedNetworks.psn_edgelists — Function
    psn_edgelists(vertlists; df_out = true)

Flatten the output of samplenetwork (a dictionary from perceiver name to that perceiver's list) into one edgelist with a row per (perceiver, pair). Columns: perceiver, from, to; if the lists were generated with moreinfo = true, also bin (the degree bin, e.g., "1:2" or "3") and real (whether the pair is a real tie). Each pair is sorted alphanumerically. Return a DataFrame, or a Matrix if df_out is false.

source
SamplingPerceivedNetworks.edgelist — Function
    edgelist(graph; df_out = true)

Extract the sociocentric edgelist of graph (a MetaGraph with :name vertex properties) as node names. Return a DataFrame with columns from and to, each row sorted alphanumerically; if df_out is false, return the raw Matrix of names in the graph's edge order (rows are not sorted).

source

    countdesired(desired)

Total number of relationships in a desired specification, i.e., the sum of all (# real, # counterfactual) entries: the target list length per perceiver.
